1Flashcard Recognition Quiz1. Log in and navigate to the Quiz section from the dashboard
2. Select 'Flashcard Quiz' mode
3. A handshape image is displayed on screen
4. Four letter choices are shown below the image
5. Click the letter I think matches the displayed handshape
6. The app immediately shows if the answer is correct or incorrect
7. The next flashcard is displayed automatically
8. After all cards are answered, the session score is shown		Input Files:
1. Bundled ASL handshape image set (A–Z)
2. Quiz question set (randomized)

User Input:
1. Letter choice selection (A, B, C, or D button)		Output Display:
1. Handshape image displayed prominently
2. Four multiple-choice letter buttons
3. Correct / Incorrect feedback after each answer
4. Progress indicator (e.g., Card 3 of 10)
5. Final score summary at end of session (e.g., 8/10 correct, 80%)		Acceptance Criteria:
1. I am shown one handshape image at a time with four letter choices. (SD-FQ-AC1)
2. After I select an answer, the app tells me immediately if I was correct or incorrect. (SD-FQ-AC2)
3. The correct answer is revealed if I choose incorrectly. (SD-FQ-AC3)
4. Questions are randomized each session so I do not see the same order repeatedly. (SD-FQ-AC4)
5. A progress counter shows me how many cards remain in the session. (SD-FQ-AC5)
6. At the end of the session, I can see my total score and accuracy percentage. (SD-FQ-AC6)
7. No webcam or internet connection is required to use this mode. (SD-FQ-AC7)

Error Prompts:
· 'Quiz data could not be loaded. Please reinstall the application.'		SD || User:
