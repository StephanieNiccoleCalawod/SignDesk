1Create Account
(Local Registration)		1. Open the SignDesk application
2. Click 'Create Account' on the login screen
3. Enter a username and password
4. Confirm the password in the Confirm Password field
5. Click Register
6. A confirmation message appears and the app redirects to the Login page		Input Fields:
1. Username text field
2. Password text field
3. Confirm Password text field		Output Display:
1. SignDesk application logo
2. Registration form (username, password, confirm password)
3. Confirmation message on successful registration
4. Redirect to Login page

Buttons:
1. Register button		Acceptance Criteria:
1. I can register using a username and password stored locally on my device. (SD-A01-AC1)
2. All required fields are validated before I can submit the form. (SD-A01-AC2)
3. My account data is saved to the local database on my device. (SD-A01-AC3)
4. If I enter a username that already exists, I see an error and can choose a different one. (SD-A01-AC4)
5. The password and confirm password fields must match before registration proceeds.
6. No internet connection is required to create an account.
7. After successful registration, the app takes me to the Login page.

Error Prompts:
· 'This username already exists. Please choose another username.'
· 'Password and confirmation password do not match.'
· 'Please fill in all required fields.'		SD || User:
