1ASL Alphabet Chart1. Open the SignDesk application and log in
2. Navigate to the Sign Language Dictionary or Reference section from the dashboard
3. Browse the full ASL alphabet chart displayed on screen
4. Click on any letter to view an enlarged image of the handshape		Input Files:
1. Bundled ASL alphabet reference images (A–Z)
2. Letter selection (tap/click)		Output Display:
1. Grid of all 26 ASL alphabet handshape images labeled A–Z
2. Enlarged view of the selected letter's handshape on click
3. Letter label displayed below each image		Acceptance Criteria:
1. I can view all 26 ASL alphabet handshapes in a single reference screen. (SD-REF-AC1)
2. Each handshape image is clearly labeled with the corresponding letter. (SD-REF-AC2)
3. I can click any letter to see a larger version of its handshape. (SD-REF-AC3)
4. The reference chart is accessible at any time from the main navigation. (SD-REF-AC4)
5. No internet connection is required to view the chart. (SD-REF-AC5)
